# Yocto Tutorial: Runtime Dependency with RDEPENDS

This tutorial demonstrates how to use the `RDEPENDS` variable in a Yocto recipe by creating a simple program that depends on the `pciutils` package. The `pciutils` package is used to run the `lspci` command, showcasing how to declare and manage runtime dependencies in Yocto.

## Project Overview

We will create a Yocto recipe that compiles and installs a user application (`my_userprog.c`). This application calls the `lspci` command at runtime. Since `lspci` is provided by the `pciutils` package, we will declare `pciutils` as a runtime dependency using the `RDEPENDS` variable.

### File Structure
The project file structure is as follows:

```
mydepends$ tree
.
├── files
│   └── my_userprog.c
└── mydepends_1.0.0.bb
```

### Recipe File: `mydepends_1.0.0.bb`
Below is the content of the Yocto recipe file, with comments explaining each line:

```bb
# Provide a brief description of the recipe
DESCRIPTION = "Yocto recipe to show-case the use of the RDEPENDS"

# Use the description for the summary
SUMMARY = "${DESCRIPTION}"

# Author details
AUTHOR = "Mahendra Sondagar (mahendrasondagar08@gmail.com)"

# Specify the license type for the application
LICENSE = "MIT"

# Checksum of the license file to ensure integrity
LIC_FILES_CHKSUM = "file://${COMMON_LICENSE_DIR}/MIT;md5=0835ade698e0bcf8506ecda2f7b4f302"

# Specify the source code location
SRC_URI = "file://my_userprog.c"

# Define the working directory for the build
S = "${WORKDIR}"

# Declare runtime dependency on the pciutils package
RDEPENDS:${PN} = "pciutils"

# Compilation process
# - Use the compiler (CC) to compile the application
# - Include any linker flags (LDFLAGS)
# - Produce the executable named 'my_userprog'
do_compile() {
    ${CC} my_userprog.c ${LDFLAGS} -o my_userprog
}

# Installation process
# - Create the target directory in the image root
# - Install the compiled executable to /usr/bin with proper permissions
do_install() {
    install -d ${D}${bindir}
    install -m 0755 my_userprog ${D}${bindir}
}
```

### User Application Code: `my_userprog.c`
This application demonstrates the usage of the `lspci` command. Below is the code with comments:

```c
#include <stdio.h>
#include <stdlib.h> // Required for system() function

int main(void)
{
    // Print a message to indicate the purpose of the program
    printf("Hello world, This is lspci example\n");

    // Execute the lspci command to list PCI devices
    system("lspci");

    // Return success
    return 0;
}
```

## Step-by-Step Guide

### 1. Create the File Structure
Organize the files as shown in the file structure above. Ensure the recipe and source files are placed in the correct directories.

### 2. Write the Recipe
Copy the contents of `mydepends_1.0.0.bb` into the recipe file located in your Yocto layer's `recipes-example/mydepends` directory.

### 3. Add the Source File
Place the `my_userprog.c` file inside the `files` directory within the recipe folder.

### 4. Build the Recipe
Run the following commands to build the recipe:

```bash
bitbake mydepends
```

### 5. Deploy and Test the Application
1. Deploy the built image or package to the target device.
2. Run the installed program on the target device:

```bash
/usr/bin/my_userprog
```

3. Verify that the output includes the PCI device list generated by the `lspci` command.

## Explanation of RDEPENDS
- **RDEPENDS:** The `RDEPENDS` variable specifies runtime dependencies for a package. When the package is installed on the target device, the specified dependencies will also be installed automatically.
- In this tutorial, the application requires the `pciutils` package to execute the `lspci` command. Declaring `RDEPENDS:${PN} = "pciutils"` ensures that `pciutils` is installed along with our application.
